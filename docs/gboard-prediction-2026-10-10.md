# Gboardを参照した確定後の予測と個人学習（0.14.1）

「今日は」を確定した後、読みを追加しなくても次の語句の候補が出るようにした。候補を選ぶと確定済みの文章へ一度だけ追加し、さらに次の候補へ進める。12キー・日本語QWERTYで同じ処理を使う。

## 調査

2026-10-10にGoogle公式の次の資料を確認した。

- [Gboard: 入力候補を表示して間違いを修正する](https://support.google.com/gboard/answer/7068415?hl=ja)：候補帯、次の単語の候補、不要な候補の長押し削除、辞書への追加。説明には言語・機能ごとの制限があるため、英語向けSmart Composeや校正を日本語の機能として扱わない。
- [Gboard: 問題を解決する](https://support.google.com/gboard/answer/9058584?hl=en)：端末で覚えた単語を削除する操作と、保存した単語の取り扱い。
- [Google Research: A Scalable Approach for Partially Local Federated Learning](https://research.google/blog/a-scalable-approach-for-partially-local-federated-learning/)：Gboardへの個人化の適用。Gboard内部のモデル、学習データ、候補順位は公開されていないため、本実装と同一とは扱わない。

固定版Mozc `60fe4012` の `protocol/commands.proto`、`converter/converter.cc`、`prediction/zero_query_decoder.cc`、`converter/history_reconstructor.cc` も確認。モバイル向けの `zero_query_suggestion` と `mixed_conversion` を使用する。0.14.0では「今日は」「学校」などのエンジン候補が0件だったが、原因は `ReconstructHistory` が数字・英字だけを扱うことを見落とし、日本語の品詞情報を渡せていなかったことだった。0.14.1では確定文字を逆変換し、辞書の変換候補から読み・表記・品詞IDを復元した履歴を渡す。これにより、定型文表への個別登録をせず、名詞・動詞・形容詞・助詞付き語句・複数文節・未知の製品名でも辞書の接続コストに基づく候補を取得できる。復元時には学習を行わず、候補の照合は文節数64・試行4096までに制限する。日常の定型文候補は補助として残している。Gboard実機の候補順位や同じ言葉の出現確率を再現したものではない。

## 0.14.1の一般語への対応

「学校 → に」「仕事 → する」「日本語 → の」「楽しい → です」「食べる → と」「学校に → は」など、定型文表に含まれない語も初回から予測できる。履歴がなく個人学習をオフにした状態でも動作する。任意の語のつながりの学習も共通処理であり、「映画 → 見る」などを確定すると次回以降に優先する。

標準の候補は品詞に応じた助詞・語尾、Mozcの辞書にある続き、対応する絵文字などが中心。過去の入力に基づく具体的な続きは端末内学習で追加する。

## 実装と操作

| 操作 | 動作 |
| --- | --- |
| 「今日は」を確定 | 「いい天気」「晴れ」「ありがとう」などの候補を表示 |
| 「いい天気」を選択 | 「今日はいい天気」を入力し、「ですね」「です」を表示 |
| 「今日は」の後に「学校」を確定 | 次回の「今日は」では「学校」を優先。IME再起動後も保持 |
| 読みを入力 | Mozcの変換・前方予測に、過去に確定した候補の頻度と新しさを反映 |
| 候補を長押し | 削除の確認を表示。選んだ語の独自学習を除き、以後の候補帯で非表示にする |
| キーボードの歯車 | 「予測・学習」を開き、次の語句の予測、個人学習、シークレットを切り替え |
| 個人学習をオフ | 個人の履歴を順位に使わず、新たな確定を学習しない。標準の予測は使用可能 |
| シークレットをオン | 個人候補・学習・確定後の予測を停止。通常の辞書変換は使用可能 |
| 学習データを削除 | 確認後、独自学習・候補の非表示リスト・Mozcの学習を削除。設定は維持 |

アプリとIMEの設定共有を必要としない、IME内の設定パネルを追加した。次の語句の予測と個人学習の設定はIME専用ファイルへ保存し、シークレットは現在のプロセス内だけで保持する。既存のアプリ側のキー設定共有の制約は変わらない。

入力データはネットワークへ送らない。独自学習は最大512件の読み・確定語・直前の確定語・使用回数・時刻、非表示の語は128件。各語は最大128文字。保存はUTF-8で一時ファイルへ完全に書いてから置き換える。選択した候補が読みの補完だった場合も、以後の読みから呼び出せるよう確定後候補の読みを逆変換する。

予測の文脈は現在の入力欄でIMEから確定した直前の語。入力欄の切替、外部のカーソル移動、削除、改行／送信、貼り付け、直接文字入力、キーボードを閉じる操作などで破棄する。以前から入力欄にある文章を取得して学習する処理は追加していない。古い入力欄・読み・候補の非同期応答とタップは無効にし、挿入失敗時には学習や文脈更新を行わない。

パスワード、電話番号、メール、URL、ワンタイムコード、属性の取得に失敗した入力欄では個人学習と確定後の予測を使用しない。通常文字またはSDKの汎用入力パターンだけを許可する。完了通知が来ない互換入力欄では学習を停止する。BASICモードでも使うIME自身の辞書・プロファイルと同じ専用領域を使用し、ネットワークやクリップボードアクセスを追加していない。

個別候補の削除は独自学習の削除と表示の抑制。Mozc内部の当該語だけの完全削除ではない。すべての学習データの削除ではMozcの履歴も削除する。
