# 絵文字入力

Pura70 / HarmonyOS7向け0.10.0（versionCode100009）に、オフラインの絵文字パネルを追加。

- 12キーの「☺︎記」、または未入力時のツールバーの顔アイコンから開く。
- 表情、気持ち、動物・自然、食べ物、お出かけ、暮らしの6カテゴリ、計144種類。完全なUnicode絵文字一覧、検索、最近使った項目の保存、肌色選択メニューは未実装。
- 1項目をUTF-16の1文字に分解せず、絵文字列全体として既存の直列化された入力処理へ渡す。未確定かながある場合は先に確定する。編集先が変わった古い入力は送らない。
- カテゴリ変更時は一覧の先頭へ戻る。縦画面は4段を収め、横画面は領域に応じてスクロールする。
- 下部から直前の入力方式へ戻る、記号へ移る、削除、改行ができる。候補バーとキー間隔の設計は維持する。

## 検証

`node tools/test-conversion-controller.cjs`で、通常絵文字・ハート・肌色付き・国旗・家族の結合列を100回キュー投入し、列が欠けないことを検証。未確定かなの一度だけの確定、プレビュー非対応での挿入、古い編集先の無効化も確認する。削除は既存のOS編集APIに任せ、実機で結合列が丸ごと消えるか確認する。

`python3 tools/test-emoji-device.py`は完全アクセスモードの実機で、アプリ所有の単行・複数行の入力欄、絵文字のタップ・削除、24連続タッチ、入力方式への復帰、記号、回転を検証する。外部アプリや基礎モードでの絵文字試験はこの段階では実施していない。

画像・結果・署名確認は`artifacts/phase9/`。設定の共有・永続化は引き続き承認済みdata-group-idの準備後に対応する。
