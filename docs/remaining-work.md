# MVPの到達点と残りの作業

最初のMVP「フリック→未確定かな→Mozcの漢字候補→タップで確定」は達成済み。文節変換・伸縮・再変換・予測・学習、日本語QWERTY、横画面にも進んでいる。各段階の実機証拠はREADMEから参照する。アプリ所有の入力欄での検証を、すべての外部アプリでの確認と混同しない。

普段使いに向け、以下を優先する。

1. **設定の保存とIMEへの反映**。アプリ設定画面はあるが、現在は変更を無効にしている。承認されたdata-group-idと対応する署名プロファイルが未取得。アプリとIMEの共有領域を構成してから、設定の変更・再起動・基礎モードを検証する。承認なしで共有できるとは扱わない。
2. **他アプリでの互換性と入力の安定性**。ブラウザー、チャット、検索、パスワードなどの実入力欄で、連続入力、カーソル、削除、フォーカス移動、確定と送信、基礎／完全アクセスの挙動を確認する。速度の試験値を記録し、測定以上の性能を主張しない。
3. **表示とアクセシビリティ**。ダークモード、大きな文字、読み上げ、タブレットでの表示を整える。横画面は導入済みだが、タブレット実機の動作確認を意味しない。
4. **配布準備**。正式署名、導入案内、ライセンス表示、プライバシー説明、対象端末／OSの範囲、更新・データ移行を確認する。現在の署名済みHAPはデバッグ用。

絵文字は段階9で初期セットを追加。クリップボードは段階10でテキストの貼り付けと一時履歴を追加。クリップボードのピン留め・永続保存、ユーザー辞書の編集、絵文字履歴の永続化・検索UIの細部、音声入力、多言語切り替えは拡張機能であり、当初MVPの未達項目ではない。
