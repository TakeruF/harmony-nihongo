# Gboardを参照したパネル配置と実機検証（0.13.0）

`origin/main` の `8d3b183d7c22a611e2dc294751e0963cd3f64d2e` を取得した後、クリップボードと絵文字パネルを調整した。

## 参照と変更

OPPO Find X9 ProのGboard日本語12キーをOPPO Connectの実画面で参照。クリップボードの通常時・選択時と絵文字パネルを確認した。参照のバージョン番号は今回取得していないため、2026-10-09のAndroidエミュレータと同一版とは扱わない。

| 変更前 | 0.13.0 | 理由 |
| --- | --- | --- |
| 一覧と下部の大きな戻る・削除ボタン | 左上の円形戻る、右上の切替・編集、2列のカード | Gboard実画面の配置へ合わせる |
| 一時履歴の再利用と削除 | 選択時に上部の削除・固定・追加、未選択時は操作を無効化 | 操作位置と選択状態を明確にする |
| 固定保存なし | 明示的に固定したクリップと切替状態を保存 | 再起動後も固定した内容を残す |
| 絵文字のタイトルと検索 | 左上の戻ると検索ピル、カテゴリ、下部の入力方式・絵文字選択 | パネルを戻る操作と配色を揃える |

参照画面の幅608pxに対し、通常時の戻る・切替・編集の中心は39・485・569px。Pura 70では画面幅で正規化した中心位置の差を1.8%以内として検証した。カードの余白、アイコンの大きさ、薄い紫の背景も参照画面から調整した。全画素の一致を検証したものではない。

## データと入力

最大10件、未固定のクリップは1時間で期限切れ。通常履歴はディスクへ保存しない。固定したテキストだけを完全アクセスモードのIME専用領域に保存する。固定解除で1時間の保持を再開し、無効化では通常履歴を消して固定内容を残す。クリップボードの読み取りはユーザーが押すHarmonyOSの標準`PasteButton`から行う。

追加画面のかな・日本語QWERTY・絵文字と、その中の絵文字検索はキーボード内で編集する。アプリの入力欄へ送らず、保存時にクリップとして追加する。入力先が変わった場合は編集中の内容を破棄する。ローカル編集ではUTF-16を明示的に走査し、絵文字や結合文字を途中で削除しない。

## 検証と証跡

対象はHuawei Pura 70 / ADY-AL10、HarmonyOS `7.0.0.109(SP6C00E105R5P2)`、完全アクセスモード。Debugビルド、署名検証とインストールを実施した。実機の入力検証はアプリ所有の試験入力欄を使用し、他のすべてのアプリで同じ結果を保証するものではない。

```sh
node tools/test-clipboard-history.cjs
node tools/test-clipboard-store.cjs
node tools/test-clipboard-composition.cjs
HDC_SERVER_PORT=8710 python3 tools/test-gboard-panels-device.py --target <HDC_TARGET>
```

ホストの`tools/test-*.cjs`は全件成功。履歴の上限・期限・固定、ファイル保存・再読み込み・失敗時の保持を検証した。Unicodeの絵文字カタログ3,653シーケンスについて、ローカル削除とカーソル境界を`Intl.Segmenter`と照合した。実機では、配置、標準貼り付け、かな・絵文字・ローマ字によるクリップ追加、固定、再起動、オン／オフ、横画面、削除と戻るなど15シナリオが成功。追加画面内の絵文字検索と絵文字の完全削除も別途確認した。

Huaweiブラウザの管理下にある試験ページでも、かな入力・確定・削除、ブラウザでコピーしたテキストのアプリへの貼り付けを確認した。試験用の入力欄を空に戻し、ポート転送とローカルサーバーを終了した。ChatGPTなど他の外部アプリについては今回の0.13.0で再検証していない。

実機ログと画面は [artifacts/gboard-panel-parity-2026-10-10](../artifacts/gboard-panel-parity-2026-10-10) に保存。`panel-device-results.json`が各シナリオの結果、`device-tests.log`と`browser-device-tests.log`が実行ログ、`verification-summary.json`がインストール済みバージョンとHAPのハッシュ。

## 残る差

OSの標準貼り付けアイコン、フォントと絵文字の描画はHarmonyOS側のものを使用する。Gboardの自動収集、すべての並び順・長押しメニュー、GIF・ステッカー・音声、記号画面全体は未対応。今回合わせたのはクリップボードの配置と操作、絵文字パネルの戻る・検索・配色であり、Gboard全体の完全一致ではない。
