# 地球儀キーと絵文字カテゴリの修正

ユーザー提供のPura 70の画面に合わせ、キーボード内の地球儀キーを撤去した。かな12キーでは未入力時も濁点・半濁点・小文字キー、英字12キーでは大小文字キーを表示する。HarmonyOSが描く下部の入力法切替はそのまま利用する。

以前は入力欄へのプレビュー反映後に、地球儀から濁点キーへ切り替えていた。最初のかなと濁点を素早く続けて押すと、その描画待ちが操作へ影響する可能性があった。常時表示によって、この非同期の切り替えを撤廃した。操作キー押下時は、進行中のフリックを先に処理してから文字を変形する既存の順序を維持する。

絵文字のカテゴリと最近使った絵文字のアイコンは、非選択時を`#737782`、選択時を`#1A1B21`に統一。選択時の青い背景は維持する。SVGの輪郭を保つため、形状が同一の灰色・黒のリソースを切り替える。

Huawei Pura 70 / ADY-AL10、完全アクセスモードで、Debugビルド・署名検証・更新インストールを実施。縦横での入力継続、かな変換と確定、検索アクション、濁点キーの常時表示を確認した。ホストテストでは、かなの指を離す前に変形する操作、半濁点の2連打、小文字フリック、遅れて届く離脱イベントによる二重入力の防止を検証した。

実機では「か→が」「は→ば→ぱ」「つ→っ」を連続タッチで確認し、140タッチで「がぱっ」20組、60文字が欠落なく入力・確定された。全140タッチの実測時間は15.069秒。`uinput`に指定した押下・間隔はそれぞれ10msだが、ツール内部の待機時間を含むため10msごとの実タッチとは扱わない。人による両手の高速入力や、すべての外部アプリでの再現性は、この自動試験では確認していない。

画面とログ、署名済みHAPは[artifacts/keyboard-icon-fix-2026-10-10](../artifacts/keyboard-icon-fix-2026-10-10)に保存。`focused-results.json`が連続入力結果、`input-device-tests.log`が縦横・変換等の結果、`emoji-final-check.log`と`emoji-{faces,people,recent}.png`が最終SVGリソースでの確認。試験入力欄は最後に空へ戻した。
