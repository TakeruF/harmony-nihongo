# アプリ設定とIMEの共有

設定画面はアプリ内の`pages/Settings`に置く。アプリの「設定」ボタンから開く。キーボード内で設定ページを表示・拡張しない。

基礎モードのInputMethodExtensionAbilityは、メインアプリと独立したサンドボックスで動く。共通イベントや他Ability起動も制限されるため、アプリのPreferencesを書くだけではIMEへ設定が反映されない。公式の共有サンドボックスを使い、アプリは設定JSONを書き、IMEは読み取る。[Huawei公式・入力法安全モード](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ime-kit-security)

## 現在の状態

共有領域の`data-group-id`は未取得。標準設定（フリックのみ、全角スペース、3モード）でかな入力を使える。アプリ設定の変更操作は未反映と誤解されないよう無効にしている。日本語QWERTY、横画面のQWERTY選択、英字12キーも未対応と表示。

承認後の接続コードは実装済みだが、共有領域への実機アクセス・設定のアプリ→IME反映は未検証。キーボードの歯車からアプリを開く機能は完全体験モード用。基礎モードではアプリをランチャーから開く。

## 申請と接続

1. AppGallery Connect → 開発与服务 → このアプリのプロジェクトとアプリを選択。
2. 项目设置 → 开放能力管理 → 输入法应用内数据共享 → 申请。
3. AGCのアプリ名・appId・開発者Idと、下記の申請文案、端末でIMEとして表示・有効化できる画面を用意する。アプリ未登録の場合は、先に`com.takeruf.harmonynihongo`を対象として登録する。
4. 承認された`data-group-id`を取得したら、`python3 tools/configure-data-group.py <承認されたID>`でソースとIMEの`dataGroupIds`を設定。
5. DevEcoで承認IDを含む署名profileを再生成して適用し、再ビルド・インストールする。既存profileの手動改変で代用しない。
6. アプリ設定を変更後、別アプリの入力欄を開き、IMEで設定反映を確認する。IME・アプリの再起動、全角/半角空白、フリック/連続タップの排他設定も検証する。

## 申請理由の文案

以下のappId・开发者IdはAGCの実際の値に置き換える。申請はまだ送信していない。

```text
应用名称：Harmony Nihongo
包名：com.takeruf.harmonynihongo
应用 appId：[AGC中显示的应用appId]
开发者Id：[华为开发者账号的开发者Id]

本应用为HarmonyOS原生离线日语输入法，已使用InputMethodExtensionAbility实现第三方输入法注册、假名滑动输入、预上屏和确认输入，并在HUAWEI Pura 70 / HarmonyOS 7上验证基础模式下的输入功能。

申请输入法应用内数据共享，用于主应用设置页面向输入法扩展提供键盘偏好配置。共享内容仅包含半角空格、输入模式切换、仅滑动输入和仅九宫格连续点击输入等布尔配置。主应用写入共享配置文件，基础模式的输入法扩展只读此文件。

用户输入文本、输入历史、转换学习数据不写入该共享文件。基础模式下不通过公共事件或其他IPC机制向扩展外传递用户输入数据。
```

候補・学習の実装が進んで申請範囲を変える場合は、実際の用途に合わせて文案も更新する。
